## 🚀 SaaS

| Produto | O que faz | Pacote Laravel |
|---|---|---|
| **[NotifyKit](https://notifykit.app.br/)** | Notificações em 11 canais (e-mail, SMS, push, WhatsApp, Telegram, Slack, Discord, Teams...) com campanhas em massa e webhooks assinados | [`notify-service-for-laravel`](https://github.com/risetechapps/notify-service-for-laravel) |
| **[Orchestrator](https://orchestrator.app.br/)** | API gateway de dados brasileiros: CNPJ, CPF, CEP, IBGE, FIPE, câmbio, B3, indicadores do BC, NCM, PIX e frete white label | [`orchestrator-link-for-laravel`](https://github.com/risetechapps/orchestrator-link-for-laravel) |
| **[Fusion Report](https://fusionreport.app.br/)** | Geração de relatórios JasperReports (JRXML) por API, em PDF, XLSX, DOCX, CSV e outros formatos | [`fusion-report-client`](https://github.com/risetechapps/fusion-report-client) |

## 📦 Pacotes open source

| Pacote | Descrição |
|---|---|
| [`geonames-for-laravel`](https://github.com/risetechapps/geonames-for-laravel) | Regiões, países, estados e cidades com dados locais, lazy loading, cache e trait `HasGeonames` |
| [`monitoring-for-laravel`](https://github.com/risetechapps/monitoring-for-laravel) | Monitoramento e logs de aplicações Laravel |
| [`api-key-for-laravel`](https://github.com/risetechapps/api-key-for-laravel) | Gestão de API keys para Laravel |
| [`risetools`](https://github.com/risetechapps/risetools) | Coleção de macros e helpers para Laravel |

Todos os pacotes são compatíveis com **PHP 8.4 / Laravel 12** e passam por uma pipeline de qualidade com PHPCompatibility, Rector e PHPStan/Larastan.
